## Important interpretation

The results are for this dataset and this fixed stratified holdout split only. They are not evidence of clinical validity.

The input CSV contained a large number of exact duplicate rows. Removing them before splitting is therefore a key part of the experimental protocol.

The majority baseline obtains 54.10% accuracy by predicting the positive class for every test case because the deduplicated data contain 54.30% positive cases. This demonstrates why accuracy alone is not sufficient.

SMOTE Logistic Regression and the Neural Network both achieve 81.97% accuracy on the held-out test set. The Neural Network has the highest ROC-AUC among the models tested (0.8864), while SMOTE Logistic Regression has ROC-AUC 0.8810. These are descriptive results, not a claim that the neural network is clinically superior.
