# Explainable and Imbalance-Aware Heart Disease Diagnostic Aid

A reproducible machine-learning project built from the supplied `heart.csv` dataset.

## Project objective

The project compares interpretable and more complex classifiers for binary heart-disease risk prediction while explicitly studying class imbalance and explainability.

Models:
1. Majority-class baseline
2. Logistic Regression
3. Logistic Regression with class weights
4. Logistic Regression + SMOTE
5. Decision Tree
6. Random Forest
7. Neural Network (MLP)

Explainability:
- Decision-tree visualization
- Tree feature importance
- Random-forest feature importance
- Permutation importance
- SHAP explanations where supported/installed

## Important dataset note

The supplied CSV contains 1,025 rows and 14 columns (13 predictors + `target`), with no missing values. It contains 723 exact duplicate rows, leaving 302 unique observations.

The training pipeline removes exact duplicate rows before the train/test split. This is important because retaining the repeated rows can make evaluation misleading.

## Setup

Python 3.10+ is recommended.

```bash
python -m venv .venv
```

Windows:
```bash
.venv\Scripts\activate
```

macOS/Linux:
```bash
source .venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## Train all models

From the project root:

```bash
python src/train.py
```

This will:
- load `data/heart.csv`
- remove exact duplicate rows
- create a stratified 80/20 train/test split
- evaluate the majority baseline
- train logistic regression
- train class-weighted logistic regression
- train SMOTE logistic regression
- train a decision tree
- train a random forest
- train an MLP neural network
- save metrics to `reports/model_results.csv`
- save confusion matrices and ROC/PR plots
- save trained models to `models/`

## Generate explainability outputs

```bash
python src/explain.py
```

This creates feature-importance and SHAP/importance figures under `reports/figures/`.

## Run the Streamlit app

After training:

```bash
streamlit run app/app.py
```

The application is a research/educational prototype. It is **not a medical diagnostic device** and should not be used to make clinical decisions.

## Reproducibility

The project uses fixed random seeds (`42`) wherever applicable. All reported metrics should be generated by running the supplied training code against the included CSV.

## Dataset columns

The supplied CSV uses:

- `age`
- `sex`
- `cp`
- `trestbps`
- `chol`
- `fbs`
- `restecg`
- `thalach`
- `exang`
- `oldpeak`
- `slope`
- `ca`
- `thal`
- `target`

The dataset's existing encoded values are preserved by the training pipeline.

## Caveat

This dataset is relatively small after duplicate removal (302 unique rows). Results should therefore be interpreted as an experimental study, not as evidence of clinical validity or real-world diagnostic performance.
